# 10-minute presentation outline

1. Problem and users (1 min)
2. Architecture and data model (1 min)
3. Customer shopping flow (2 min)
4. Vendor onboarding and product management (1.5 min)
5. Cart, order lifecycle, payment verification and commission (2 min)
6. Search, caching, S3, admin analytics (1 min)
7. Testing, challenges, results, limitations and next steps (1.5 min)

Use real screenshots and measured test results. Do not invent performance numbers; record actual results after testing.
