# Individual Reflection
## Nexvia FS01 – Multi-Vendor Marketplace

### 1. Introduction

Working on the Nexvia FS01 Multi-Vendor Marketplace project provided me with practical experience in full-stack web development and modern application deployment.

The project helped me understand how different technologies work together to build an e-commerce platform.

### 2. My Contributions

During the project, I worked on and contributed to:

- React frontend development and product details navigation.
- Product reviews and ratings functionality.
- Backend API integration using Node.js and Express.js.
- Review validation based on customer orders and payment status.
- MongoDB integration and application data handling.
- Troubleshooting Redis and Elasticsearch integrations.
- Deployment verification using Vercel and Render.
- Architecture, API and testing documentation.

### 3. Technical Skills Gained

Through this project, I gained practical exposure to:

- React.js and frontend development.
- Node.js and Express.js.
- MongoDB Atlas.
- REST API integration.
- Redis caching.
- Elasticsearch product search.
- AWS S3 image storage.
- Razorpay test payment integration.
- Git, GitHub and cloud deployment.

### 4. Challenges Faced

Some of the challenges I encountered included:

- Resolving frontend and backend integration issues.
- Configuring database and external service connections.
- Troubleshooting deployment errors.
- Fixing product navigation issues.
- Implementing review eligibility and order ID validation.

I improved my debugging and problem-solving skills by identifying errors, understanding their causes and applying appropriate solutions.

### 5. Key Learnings

This project helped me understand:

- How a full-stack application works.
- How frontend applications communicate with backend APIs.
- How to manage data using MongoDB.
- How to integrate third-party services.
- How to use GitHub for version control.
- How to deploy applications using cloud platforms.
- Why security and server-side validation are important.

### 6. Conclusion

The Nexvia FS01 project was a valuable learning experience. It improved my technical knowledge, debugging abilities, teamwork and confidence in developing real-world web applications.

I gained practical experience in building, integrating, troubleshooting and deploying a full-stack marketplace application.

This experience will help me in my future software development career.
